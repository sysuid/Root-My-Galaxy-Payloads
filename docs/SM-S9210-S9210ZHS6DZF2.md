## Publication status

The source profile is firmware-derived, but no exploit or KernelSU artifact is
published in `targets-v3.json` yet. A production root claim requires a build
with an Android NDK and an on-device run that validates the physical P0 oracle,
slide discovery, overwrite path, and KernelSU late-load behavior on this exact
firmware. Do not substitute artifacts from a different model or build.
